- Neshan API migration (replacing Nominatim/OSRM): out of scope — current free APIs work for Iran; migration is a separate effort requiring API key setup. Noted as future work in plan maintenance notes.
- Adding a test infrastructure (Jest/Vitest): out of scope — the project has no test runner configured and adding one is a separate initiative. This plan's verification is via lint + build + grep + optional manual browser check.
- Mobile-responsive floating card adjustment for narrow screens: low priority, noted as future refinement.
- Parallel `Promise.all` for OSRM `fetchAllRoutes`: rejected. The web-mapping skill and OSRM public demo server (`router.project-osrm.org`) require sequential segment fetches; concurrent requests 429. Left `src/utils/routing.ts` unmodified.
- Editing `src/index.css` for the accuracy circle or toast: rejected. Pulse-marker CSS already exists; `Circle` and toast use react-leaflet / Tailwind.
- Editing `src/components/ControlPanel.tsx` for "نقطه X" labels: rejected. The sidebar already interpolates `wp.label`.
- Pushing GPS into the `waypoints` array: rejected. User location is a separate overlay; inserting it would create a phantom measure point and pollute segment math.
- Wiring GeocodedMarker popup delete (`onRemove={() => {}}`): deferred. Removal already works from ControlPanel; mixing it into this plan is scope creep.
- Ionic Framework UI (`@ionic/react`, ion-header, ion-fab): rejected for plan 002. Capacitor is the native shell; the existing React/Leaflet/Tailwind UI stays.
- Background location (`ACCESS_BACKGROUND_LOCATION`, iOS `UIBackgroundModes: location`): rejected. GPS is one-shot on the location FAB (`watch: false` today).
- Committing `server.url` in `capacitor.config.ts` for Vite live-reload: rejected. That would point production WebViews at a developer machine. Local-only follow-up.
- Dropping `tsc -b` from cap scripts (`"vite build && npx cap copy"` as sketched): rejected. `cap:build` / `cap:sync` must go through `npm run build`.
